# Hi, I'm Shikha

I'm a frontend developer and designer based in the Netherlands. I work mostly with Vue, Nuxt and React, and I usually design a feature in Figma before I build it, so I see it from both sides.

At TAUS I helped move taus.net from Joomla and HubSpot to Nuxt with Storyblok as a headless CMS. I built the component library with the team, then trained designers and marketers to create pages with it themselves. I also brought the HubSpot blog into the main site through the HubSpot API, so it now lives on taus.net instead of a separate URL. Before that I worked on React features for the TAUS HLP platform using Redux and TanStack Query.

I'm open to new frontend roles in the Netherlands.

## What I work with

Vue 3, Nuxt, Pinia, React, Next.js, TypeScript, Tailwind CSS, Node.js, Vite, GitHub Actions, Figma
